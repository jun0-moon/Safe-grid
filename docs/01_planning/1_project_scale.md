# 1. 프로젝트 범위 설정 (Scope Definition)

## 1.1. 프로젝트 개요

- **프로젝트명:** Safe-Grid
- **서비스 목적:** 스마트폰 위치 데이터(GPS)와 공간 데이터베이스(Spatial DB)를 활용하여, 실시간 다중 밀집도를 분석하고 위험 구역(Red Zone) 및 안전 우회 경로를 안내하는 플랫폼.

## 1.2. 포함 대상 (In-Scope)

본 프로젝트에서 시연을 위해 반드시 구현해야 할 핵심 기능과 범위는 다음과 같습니다.

- **데이터 생성 및 처리 (Data & DB)**
  - 대규모 군중 밀집 상황을 연출하기 위한 가상 GPS 데이터 생성 스크립트 (Python)
  - 공간 데이터베이스(PostGIS)를 활용한 특정 폴리곤(골목길 등) 내 실시간 인구 밀집도 산출 쿼리 구현
  - 초당 수백 건의 데이터 인입 시 병목 방지를 위한 인메모리 캐시(Redis) 시스템 구축
- **백엔드 (Backend API)**
  - 클라이언트 위치 수신 및 공간 연산 결과를 반환하는 RESTful API 구축
  - 현재 위치에서 목적지까지 이동 시, 위험 구역을 배제한 '안전 우회 경로 산출 알고리즘' 적용
- **프론트엔드 (Frontend)**
  - 사용자가 별도 설치 없이 접근 가능한 모바일 반응형 웹(Web) UI 구현
  - 지도 API(카카오맵 또는 네이버 지도) 연동 및 군중 밀집도 기반 실시간 히트맵(Heatmap) 시각화

## 1.3. 제외 대상 (Out-of-Scope)

한정된 기한 내 핵심 기능(대용량 데이터 처리 및 밀집도 분석)의 완성도를 높이기 위해 다음 사항은 개발 범위에서 제외합니다.

- **네이티브 앱(Android/iOS) 개발:** 앱 스토어 배포 대신 접근성이 높은 모바일 웹으로 대체.
- **회원가입 및 로그인 시스템:** 긴급 안전 서비스의 특성상 불필요한 인증을 생략하고, 비회원 기반의 위치 정보 동의만으로 서비스 제공.
- **실제 대규모 유동 인구 데이터 수집:** 학생 수준의 인프라 한계를 고려하여, 파이썬 스크립트를 통한 '가상 더미 데이터'로 스트레스 테스트 및 시연 진행.
- **전국 단위 지도 서비스:** 시연의 완성도를 위해 대구 동성로 등 '특정 밀집 우려 구역 1~2곳'으로 공간 데이터를 제한함.

## 1.4. 제약 사항 (Constraints)

- **일정 제약:** 2026년 6월 10일(수) 최종 시연 및 결과 발표 완료.
- **자원 제약:** 4인 팀 단위로 수행하며, 비용 최소화를 위해 오픈소스(PostgreSQL, Redis) 및 클라우드 프리 티어를 적극 활용함.
