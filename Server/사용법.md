## 현재 폴더 기준

이 문서는 `C:\Users\User\Desktop\Safe-grid\Server` 폴더에서 실행하는 기준입니다.

## 가상환경 생성 (처음 1회만)

```PowerShell
python -m venv .venv
```

## 가상환경 활성화 (PowerShell)

```PowerShell
.\.venv\Scripts\Activate.ps1
```

## 패키지 설치

```PowerShell
python -m pip install -r requirements.txt
```

## 서버 실행

```PowerShell
python .\main.py
```

## 가상환경 종료

```PowerShell
deactivate
```

## PowerShell에서 활성화가 막히면 1회만 실행

```PowerShell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

그 다음 PowerShell을 다시 열고 2번 명령을 다시 실행하면 됩니다.

## 참고

`main.py`는 `uvicorn`을 사용해 FastAPI 앱을 실행합니다. `requirements.txt`에 적힌 패키지를 먼저 설치해야 합니다.
