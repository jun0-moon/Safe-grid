## 가상환경 생성 (처음 1회만)

```PowerShell
python -m venv .venv
```

## 가상환경 활성화 (PowerShell)

```PowerShell
.\.venv\Scripts\Activate.ps1
```

## 패키지 설치

```PowerShell
pip install -r requirements.txt
```

## 서버 실행

```PowerShell
python .\main.py
```

## 가상환경 종료

```PowerShell
deactivate
```

## PowerShell에서 활성화가 막히면 1회만 실행:

```PowerShell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

그 다음 PowerShell을 다시 열고 2번 명령을 다시 실행하면 됩니다.
